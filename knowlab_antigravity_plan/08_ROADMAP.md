- inspect existing app;
- identify framework;
- identify data layer;
- identify current domain modules;
- identify reusable components;
- run build/test.

### Xe máy
Specs + comparison + commuting cost + ownership.

### Nhà cửa
Area + materials + cost + renovation/build scenario.

### Phong thủy
Knowledge explorer + school-specific interpretation + comparison.
