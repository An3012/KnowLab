# KnowLab — Knowledge Engine

## 1. Mục tiêu

Knowledge Engine phục vụ **đào sâu kiến thức domain**, không phải tạo một LMS tổng quát.

## 2. Knowledge hierarchy

```text
Domain
→ Topic
→ Concept
→ Sub-concept
→ Technical Detail
→ Edge Case
→ Tool / Experiment
```

## 3. Depth model

### L0
Thuật ngữ và khái niệm nền.

### L1
Cấu trúc, thành phần, quan hệ.

### L2
Ứng dụng và bài toán thực tế.

### L3
Trade-off, phân tích, failure mode, edge cases.

### L4
Technical details, advanced reasoning, domain-specific methodology.

Người dùng có thể truy cập L3/L4 trực tiếp.

## 4. Knowledge page

Mỗi concept nên có:

- định nghĩa;
- giải thích;
- ví dụ;
- tại sao quan trọng;
- thông số liên quan;
- quan hệ;
- common mistakes;
- advanced details;
- sources;
- tool liên quan.
