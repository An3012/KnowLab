# KnowLab — Product Plan

## 1. Product positioning

KnowLab là **interactive knowledge platform cho các domain cụ thể**.

Người dùng không chỉ đọc. Họ có thể:

- tra cứu;
- đào sâu;
- xem thông số;
- hiểu quan hệ giữa các thành phần;
- tính;
- kiểm tra;
- mô phỏng;
- so sánh;
- lưu scenario;
- quay lại nghiên cứu.

## 2. Product pillars

1. Domain Knowledge
2. Structured Data
3. Domain Tools
4. Compare
5. Calculator / Simulation
6. Scenario
7. Deep Learning

## 3. User journeys

### Journey A — Tra cứu chuyên sâu

```text
Domain
→ Topic
→ Concept
→ Related Concepts
→ Technical Details
→ Source / Assumption
```

### Journey B — Chuẩn bị lựa chọn

```text
Domain
→ Goal
→ Filters
→ Candidate Items
→ Compare
→ Calculate / Validate
→ Scenario
```

### Journey C — Thực hành

```text
Tool
→ Inputs
→ Validation
→ Result
→ What-if
→ Compare
→ Save
```

### Journey D — Học nâng cao

```text
Concept
→ Prerequisites
→ L2
→ L3
→ L4
→ Edge Cases
→ Experiment
```

## 4. Domain-first navigation

Mỗi domain có:

- Overview;
- Topics;
- Tools;
- Compare;
- Scenarios;
- Glossary;
- Advanced.

Navigation không được làm người dùng phải đi qua lesson/quiz trước khi sử dụng tool.

## 5. Search

Search phải tìm được:

- concept;
- product/item;
- specification;
- glossary;
- tool;
- scenario;
- domain topic.

Kết quả phải có domain context.

## 6. Compare

Compare không chỉ là bảng text.

Phải hỗ trợ:

- normalized specs;
- criteria;
- filters;
- difference;
- trade-off;
- assumptions;
- source/date;
- side-by-side;
- mobile strategy.

## 7. Knowledge page

Mỗi knowledge page nên có:

```text
Tóm tắt
→ Thông số / khái niệm
→ Giải thích
→ Ví dụ
→ Quan hệ
→ Advanced details
→ Common mistakes
→ Tool liên quan
→ Compare liên quan
→ Source
```

## 8. Scenario

Scenario lưu:

- inputs;
- assumptions;
- outputs;
- engine version;
- data version;
- timestamp;
- notes.

Có thể duplicate/fork scenario.

## 9. Progress

Progress là phụ trợ, không phải mục tiêu.

Theo dõi:

- concept đã xem;
- concept đã hiểu/quiz;
- tool đã dùng;
- scenario đã lưu;
- domain depth.

Không biến progress thành điểm thi.

## 10. Export / share

Kiến trúc phải hỗ trợ:

- shortlink;
- readonly scenario;
- export;
- image/report;
- share.

Mỗi domain có thể có format riêng.

## 11. Homepage content

Ưu tiên:

- domain;
- tool;
- topic;
- advanced knowledge;
- recent scenarios;
- comparison;
- search.

Không ưu tiên các banner gamification.
