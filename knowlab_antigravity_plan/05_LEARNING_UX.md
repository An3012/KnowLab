# KnowLab — Learning UX

## 1. Vai trò

Learning UX là **lớp hỗ trợ người dùng hiểu sâu domain**, không phải biến KnowLab thành LMS.

## 2. Navigation

```text
Home
Domains
Topics
Tools
Compare
Scenarios
Glossary
```

Trong domain:

```text
Overview
Knowledge
Tools
Compare
Scenarios
Advanced
```

## 3. Home

Hero có thể là:

> Chọn lĩnh vực bạn muốn đào sâu

Các domain card phải dẫn trực tiếp tới domain landing.

## 4. Domain landing

Hiển thị:

- overview;
- popular topics;
- advanced topics;
- tools;
- compare;
- recent scenarios;
- glossary.

## 5. Knowledge UI

Ưu tiên:

```text
Summary
→ Core concept
→ Technical details
→ Examples
→ Related
→ Tool
→ Advanced
```

Không bắt buộc user hoàn thành quiz trước khi mở phần khác.

## 6. Explain this

Cho phép mở:

- thuật ngữ;
- công thức;
- thông số;
- kết quả;
- assumption.

## 7. Compare UX

- side-by-side desktop;
- cards/horizontal scroll mobile;
- sticky selected items;
- filters;
- criteria;
- source.

## 8. Lab UX

- clear inputs;
- unit;
- inline validation;
- result summary;
- explanation;
- what-if;
- save.

## 9. Mobile

Đặc biệt:

- PC Builder;
- Compare;
- tables;
- filters;
- sticky cart;
- charts

phải được thiết kế riêng cho mobile, không chỉ shrink desktop.

## 10. Không dùng

- gamification nặng;
- progress bar phủ toàn UI;
- quiz làm cổng khóa;
- card grid chỉ để trang trí.
